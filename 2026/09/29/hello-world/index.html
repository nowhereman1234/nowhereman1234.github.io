为什么要有这个博客

想法这种东西，放在脑子里会慢慢蒸发。写下来，它才真正属于你。

所以有了这里。不为流量，不为更新频率，只为一个能长期存放和检索自己想法的地方。

以后会写什么

大致三类：

类型 说明
技术笔记 踩过的坑、读过的源码、想明白的原理
读书摘要 读完之后还想再翻一遍的部分
随笔 没什么用，但想说

它是怎么运作的

这个站点用 Hexo 生成，主题是 Butterfly，托管在 GitHub Pages 上。

发布流程很短：

  1. 把文章交给 AI 助手
  2. 助手写入 Markdown 并运行发布脚本
  3. GitHub Pages 自动构建，一两分钟后上线

没有后台，没有数据库，也没有需要维护的服务器。

开始吧

Stay hungry, stay foolish.

—— 就用这句话开个头。
